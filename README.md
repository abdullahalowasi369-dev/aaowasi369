# aaowasi369
A personal portfolio web application by Md. Abdullah Al Owasi showcasing Technology Risk, GRC, TPRM, and AI Governance. Features interactive 7-step governance traces, an inherent vs. residual risk score model, evidence-to-control architectures (SOC 2, ISO 27001, ISO 42001, EU AI Act), and real-time CISA KEV threat signal integration.
